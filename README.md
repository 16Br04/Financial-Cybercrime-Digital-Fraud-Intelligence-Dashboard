# Financial-Cybercrime-Digital-Fraud-Intelligence-Dashboard

Phishing URL Analyzer

A Python tool that checks a URL for phishing red flags, scores it with a machine learning model, and shows what patterns are common in phishing URLs through a dashboard.

Status: Day 1 - setup and scope. (Update this as you go.)

Problem

Phishing is one of the most common entry points for fraud and cyber attacks. This project:

 1. Extracts explainable red flags from a URL (the cyber part)
 2. Classifies it as phishing or legitimate (the model part)
 3. Analyses which features and keywords separate phishing from safe URLs (the data analysis part)
